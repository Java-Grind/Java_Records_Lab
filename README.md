# Java Records Lab

Небольшая лабораторная работа на Java о records: неизменяемые данные, compact constructor, value semantics, pattern matching и границы применения.

## Установка и запуск

Нужны JDK 26 и Maven 3.9+.

    git clone <repository-url>
    cd Java_Records_Lab
    mvn compile

Запуск примеров:

    java -cp target/classes org.Lab_Main
    java -cp target/classes org.Validation_Main
    java -cp target/classes org.PatternMatching_Main
    java -cp target/classes org.Collections_Main

Описание экспериментов — в [notes/lab_work.md](notes/lab_work.md).
